# WeChat Science Post

面向中文微信公众号的科学传播写作 skill。它帮助把论文、产品安全争议和环境健康议题写成可读、克制、证据边界清楚的公众号文章，也支持已有 HTML/Markdown 推文的局部改写与排版检查。

## 适用场景

- 论文解读与文献分享
- 环境健康、食品与消费品安全科普
- 围绕热点争议的证据链拆解
- 将已有推文改得更自然、更少模板感
- 微信公众号 HTML/Markdown 的局部修改、标题和图源说明补充

## 它关注什么

这个 skill 不把“检出”直接写成“高风险”。它会在文章中分开处理：

1. 样品来自哪里，检测了什么
2. 方法和结果实际说明了什么
3. 总含量、迁移量、暴露剂量与健康风险之间还缺哪些信息
4. 哪些解释是数据支持的，哪些仍是推断
5. 读者可以追问哪些可核实的问题

这种写法适合需要准确传达不确定性、又不希望文章晦涩的科学传播场景。

## 主要能力

- 根据文章类型组织论证：文献分享、专业解读、争议分析或短资讯
- 提供论文信息、研究设计、主要发现、局限和结论边界的完整结构
- 将泛泛结论改写为与样品、方法、结果和暴露路径对应的表达
- 避免夸张风险用语和常见的刻板模板句
- 在不重做设计的前提下维护已有微信公众号 HTML 的 CSS 和版式节奏
- 为改编图、截图和论文图表补充来源与版权提示

## 使用方式

将本目录安装到 Codex 的 skills 目录，例如：

```bash
cp -R wechat-science-post ~/.codex/skills/
```

然后在对话中直接说明任务，或显式调用：

```text
Use $wechat-science-post to turn this paper into a Chinese WeChat article.
```

也可以直接提出中文需求，例如“把这篇论文写成公众号推文”“检查这段产品安全科普有没有把检出写成风险”“保留现有 HTML 版式，改写这一节”。

## 推荐的文章结构

对论文解读，默认采用以下顺序：

1. 有信息量但不过度吸引眼球的标题
2. 论文信息：中英文题名、作者、期刊、日期和 DOI
3. 这项研究为什么值得读
4. 研究设计与方法
5. 主要结果
6. 机制或解释
7. 局限与证据边界
8. 读者可带走的一句话
9. 图源、版权与来源说明

对公共争议，先还原流传中的具体说法，再区分已知事实、合理推断和待补信息；最后给出读者可追问的批次、材料层、检测方法、定量限、迁移测试、暴露估算和监管回应等问题。

## 风险表达原则

写作时会刻意区分下列概念，避免把它们混成一个判断：

| 概念 | 含义 |
| --- | --- |
| 危害属性 | 某物质在特定条件下可能造成不良影响 |
| 检出 | 在样品中测到了该物质 |
| 总含量 | 提取或消解后得到的材料层面含量 |
| 迁移量 | 在实际接触介质中释放出的量 |
| 暴露剂量 | 人实际接触或吸收的量 |
| 健康风险 | 综合剂量、途径、时长、人群和毒理阈值后的判断 |

因此，单个检测数字通常只能作为线索。要讨论健康风险，还需要与真实接触条件相匹配的迁移和暴露信息。

## 编辑已有 HTML 时

skill 会先定位目标段落，尽量保留现有 CSS 和版式节奏。修改后会针对常见的夸大用语、模板表达和待办标记做定向检查。若文章在浏览器中已打开，应在确认文件写入后再刷新预览。

## 证据与版权

- 对新闻、标准、法规和近期争议，应优先核验当前的一手来源。
- 对论文、标准和技术判断，应尽可能引用原始来源；若只能使用二手信息，要在文中说明边界。
- 不虚构品牌、检测值、DOI、发布日期、限值或法规要求。
- 使用论文截图、提取图或改编图时，应标注来源；涉及改编内容时可加入“如有侵权，请联系删除”。
